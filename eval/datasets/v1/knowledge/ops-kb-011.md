# 网关 502 排查手册

## 适用场景
API 网关集中返回 502/504，或某路由的错误率突增。

## 常见根因
1. 上游服务实例重启或发布中，连接被拒绝。
2. 上游处理超时超过网关 read timeout。
3. 上游 keepalive 配置不一致导致连接被对端关闭。

## 排查步骤
1. 定位报错路由对应的上游服务与实例。
2. 查看该服务实例的存活与发布状态。
3. 对比网关超时配置与服务 P99 延迟。

## 处理方案
- 应急：摘除异常实例，滚动重启；临时调大网关超时。
- 治理：统一网关与上游的 keepalive/timeout 配置；发布使用就绪探针。

## 相关错误码
- ERR_6002：上游连接被拒绝
- ERR_6003：上游响应超时
