# Redis 复制与 WAIT 的一致性边界

Redis 默认采用异步复制，主节点通常不等待每次写入都被副本处理才继续。副本会周期性确认收到的数据进度。WAIT 可以等待指定数量的副本确认写入，但不会把 Redis 变成强一致系统；在特定持久化和故障切换条件下，已确认写入仍可能丢失。评估切换风险时应同时考虑复制进度与持久化配置。
