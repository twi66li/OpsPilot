# Redis 集群主从切换 SOP

## 适用场景
应用批量出现 `Redis connection reset` / `MOVED` 报错，或监控显示某分片 master 发生切换。

## 排查步骤
1. 确认切换原因：`CLUSTER INFO`、集群事件日志（failover、内存淘汰、网络分区）。
2. 检查新主节点负载：连接数、内存碎片率、慢日志。
3. 确认客户端拓扑刷新策略是否启用（部分客户端需手动刷新映射）。

## 处理方案
- 应急：重启报错应用实例，或触发客户端强制刷新拓扑。
- 治理：客户端开启自动拓扑刷新与重试；为关键业务配置读写分离兜底。
- 预防：内存使用率超过 80% 提前扩容，禁止在 master 上执行大 key 删除。

## 相关错误码
- ERR_8001：Redis 连接重置
- ERR_8002：集群槽位迁移中
